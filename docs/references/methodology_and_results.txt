3.3 Embedded Approach of Feature Selection
Data quality affects the performance of any machine learning model. Even the advance model 
cannot perform well if the data is noisy (Hegazi et al., 2021). A SMAP-L4 dataset initially

exhaustive investigation into feature significance was conducted using the RF regressor, a robust 
ensemble learning method that combines multiple decision trees to improve predictive accuracy.

3.4 Gradient Boosting Regression for soil moisture prediction
 The Gradient Boosting (GB) Regressor was employed to predict the surface soil moisture by 
using the 14 important features selected through the RF embedded feature selection method. GBR 
builds an ensemble model by sequentially adding decision trees, where each new tree minimizes 
the residual errors made by the previous ensemble (Rao et al., 2019). It is a combined model with 
enhanced stability and greater performance (Shrivastav & Jha, 2021). It uses the boosting 
algorithm to solve the regression problem.  GBR minimizes a loss function using gradient descent 
(Li et al., 2018). The prediction after adding M trees is mathematically represented as

where ℎ𝑚(𝑥𝑗) represents the prediction from the mth weak learner and 𝑦𝑚 is its weight.

The GBR model was implemented using the scikit-learn library (Pedregosa et al., 2011). 
Hyperparameter tuning was systematically conducted using the GridSearchCV function. The 
parameters optimization includes, number of trees (n_estimators = 100), learning rate 
(learning_rate = 0.1), tree depth (max_depth = 3), and random state (random_state = 42). Fig. 5 
shows the general architecture of the GBR model. Setting a shallow tree depth (max_depth = 3) 
helped prevent overfitting, along with the benefit of feature selection in reducing model 
complexity. The training and evaluation process followed an 80:20 split, where 80% of the 
available data samples were used for training and 20% were used for testing. A single GBR model 
was trained and tested on data of each seven locations (Bhuj, Idar, Ankleshwar, Bhavnagar, 
Jamnagar, Vapi, and Palanpur) independently then additionally saved model on each location is 
tested on different location data to cross validate model’s predictive ability. This cross-validation 
step helped to confirm that the model works well even when applied to different environmental 
conditions. Three common evaluation metrics, MSE, mean absolute error (MAE), and R-squared 
(R²) were used to assess how well the model performed.

typical interdependency present in the data, is the foundation of the suggested prediction model. 
Using weaker learning algorithms that have been separately taught from several models, the 
ensemble machine learning algorithm combines the findings in some way, usually by averaging 
all the predictions to produce an overall better prediction. This has proven to be effective, and a 
lot of study in the field of ensemble learning has been done on it (Hegazi et al., 2021). It is highly 
helpful to predict soil moisture when a subset of geophysical properties is chosen. When the 
model's hyperparameters are set appropriately, the model's performance can potentially increase 
dramatically. One technique for choosing a model's ideal hyperparameter is GridSearchCV 
(Ahmad et al., 2022). A comprehensive approach is employed to maximize the GBR
